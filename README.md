# 我的 Zotero

本地运行的文献管理与 PDF 阅读器，界面采用 apple-minimal 设计语言。可直接导入现有 Zotero 文库（只读，不修改 Zotero）。

## 桌面版（推荐）

运行 `release/MyZotero-Setup-1.0.0.exe` 安装，桌面和开始菜单会出现「我的 Zotero」。

- 数据保存在 `%APPDATA%\MyZotero\data`（数据库、本应用存储的附件、自装 CSL 样式），卸载时不会删除
- 重新打包：`npm run dist`（生成安装包），`npm run dist:dir`（只生成 `release/win-unpacked`）
- 开发时直接以窗口运行：`npm run app`（使用项目里的 `data/`）

### 自动更新

安装版启动时会检查 GitHub Releases 上有没有新版本，有就弹窗提示，可以下载后一键重启安装（在「设置 → 通用 → 软件更新」里能手动检查，也能关掉自动检查）。

发布新版本：

1. 一次性准备：在 GitHub 创建一个 fine-grained token，只授权 `415_lab-zotero-reader` 仓库的 **Contents: Read-only**，把它粘贴到 `electron/update-token.txt`（已被 git 忽略）。它会被打包进安装包，供软件读取私有仓库的 Releases，所以不要给它更多权限。
2. 可选：把这次的更新说明写进 `build/release-notes.md`，会显示在 Release 页面和软件的更新提示里。
3. 运行 `npm run release -- 1.1.0`：改版本号、打包，并用 `gh` 的登录身份上传安装包和 `latest.yml` 到 GitHub Releases。

1.0.0 还不带更新功能，需要手动安装一次新版本，之后就能自动更新了。

## 浏览器版

```bash
npm install
npm start          # 构建前端并启动，打开 http://localhost:5417
```

Windows 下也可双击 `启动.bat`。开发模式：`npm run dev`（Vite 热更新 http://localhost:5173，API 在 5417）。浏览器版使用项目里的 `data/`，与桌面版的数据互相独立。

需要 Node.js 22.13+（使用内置 `node:sqlite`）。

## 功能

**文库**
- 分类（多级、拖拽移动、拖入条目）、未分类条目、最近添加、重复条目（检测与合并）、回收站、保存的搜索
- 条目列表：虚拟滚动、列可选/可调宽/排序、展开子条目、多选、键盘操作、拖入文件导入
- 条目详情：所有字段可编辑、作者（类型/单双字段/排序）、摘要、附件、笔记、标签、关联条目、所在分类
- 标签选择器：彩色标签（数字键 1–9 切换）、自动标签、按标签筛选、重命名/删除/设颜色、拖条目到标签上打标签
- 搜索：标题/作者/年份、所有字段和标签、所有内容（PDF 全文 + 注释）；高级搜索与保存的搜索

**添加条目**
- 通过 DOI、arXiv、ISBN、PubMed ID、网址（读取 citation_* 元数据）或论文标题添加
- 拖入 PDF 自动识别元数据（DOI → arXiv → 标题检索 CrossRef → ISBN）并创建父条目
- 查找可用 PDF（arXiv / OpenAlex 开放获取），更新元数据
- 导入 BibTeX / RIS / CSL JSON；从 Zotero 数据目录导入整个文库（条目、分类、标签、笔记、附件、注释、彩色标签、关联、全文缓存）

**PDF 阅读器**
- 多标签页、连续滚动、缩放/适合宽度、旋转、双页、横向/平铺滚动、深色页面、文档内查找、链接跳转、记住阅读位置
- 注释：高亮、下划线、便笺、文本、区域截图、手绘、橡皮擦；8 种颜色、评论、标签、改页码，坐标格式与 Zotero 一致
- 侧栏：缩略图、注释列表（搜索、按颜色/标签筛选、拖到笔记）、大纲
- 右侧：条目信息与笔记；选中文本「添加到笔记」、从全部注释生成笔记
- 导出带注释的 PDF（写入标准 PDF 注释）

**划词翻译**（Google 免费翻译）
- 在 PDF 中选中文字，弹出的工具条下方直接显示译文；可一键「高亮并写入评论」
- 注释弹窗、注释卡片菜单可翻译注释原文并填入评论；可设置创建高亮时自动把译文写入评论
- 阅读器右栏「翻译」页：自动带入最近选中的文字，也可手动输入；条目详情可翻译标题和摘要
- 「设置 → 翻译」选择源语言、目标语言，开关自动翻译

**笔记** 富文本编辑（标题、列表、引用、高亮、链接、代码、上下标），插入引注，从文库拖入条目生成引注，兼容 Zotero 笔记里的内嵌图片。

**引文与导出**
- CSL 样式：自动加载 Zotero 的 styles 文件夹，内置 GB/T 7714-2015、APA、Vancouver、Harvard，可安装 .csl
- 生成参考文献/引注（预览、复制富文本、保存 HTML/文本），快速复制 Ctrl+Shift+C / Ctrl+Shift+A
- 导出 BibTeX、BibLaTeX、RIS、CSL JSON、CSV

## 数据

- 数据库与本应用存储的附件：`data/`（可用环境变量 `MYZOTERO_DATA` 改位置）
- 从 Zotero 导入的附件保留在原处，通过路径打开；永久删除条目不会删除 Zotero 目录中的文件
- 启动时只为本应用存储的 PDF 建立全文索引；其他 PDF 可在「设置 → 搜索与索引」中手动建立（云盘文件可能会被下载）

## 未包含

Zotero 云同步、群组文库、浏览器 Connector 插件、RSS 订阅、Word/LibreOffice 插件、EPUB/网页快照阅读。
